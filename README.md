# Zımba — PDF Tools

Merge, split, compress and organize PDFs right in your browser. Images to PDF, PDF to images and page numbers. Free, offline and private: files never leave your device.

Live: https://erenbaris838.github.io/zimba/

Built with [pdf-lib](https://github.com/Hopding/pdf-lib) (MIT) and [PDF.js](https://github.com/mozilla/pdf.js) (Apache-2.0), included in `vendor/` with their licenses.
